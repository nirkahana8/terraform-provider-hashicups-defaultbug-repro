# `objectplanmodifier.UseStateForUnknown()` on a CustomType `SingleNestedAttribute` crashes with "Attribute Missing" when the attribute is unknown in the plan

### Module version

```
github.com/hashicorp/terraform-plugin-framework v1.19.0
github.com/hashicorp/terraform-plugin-go        v0.31.0
Terraform                                        v1.5.7
```

### Relevant provider source code

Schema generated by `tfplugingen-framework generate all` (so `nested` is backed by
the strict generated CustomType `NestedType`), with the stock object plan modifier
attached in the resource `Schema()`:

```go
s := gen.ThingResourceSchema(ctx) // generated; nested has CustomType NestedType
nested := s.Attributes["nested"].(schema.SingleNestedAttribute)
nested.PlanModifiers = append(nested.PlanModifiers, objectplanmodifier.UseStateForUnknown())
s.Attributes["nested"] = nested
resp.Schema = s
```

Generated schema (`internal/generated/resource_thing/thing_resource_gen.go`) — note the CustomTypes `NestedType`/`SubType`:

```go
func ThingResourceSchema(ctx context.Context) schema.Schema {
	return schema.Schema{
		Attributes: map[string]schema.Attribute{
			"id": schema.StringAttribute{
				Computed: true,
			},
			"nested": schema.SingleNestedAttribute{
				Attributes: map[string]schema.Attribute{
					"sub": schema.SingleNestedAttribute{
						Attributes: map[string]schema.Attribute{
							"ref_id": schema.StringAttribute{
								Optional: true,
								Computed: true,
							},
						},
						CustomType: SubType{
							ObjectType: types.ObjectType{
								AttrTypes: SubValue{}.AttributeTypes(ctx),
							},
						},
						Optional: true,
						Computed: true,
					},
				},
				CustomType: NestedType{
					ObjectType: types.ObjectType{
						AttrTypes: NestedValue{}.AttributeTypes(ctx),
					},
				},
				Optional: true,
				Computed: true,
			},
		},
	}
}
```

Config omits `nested`:

```hcl
resource "usfu_thing" "test" {}
```

### Expected behavior

`nested` is unknown in the plan; `UseStateForUnknown` is a no-op on create (no prior
state). Plan should succeed with `nested = (known after apply)`.

### Actual behavior

`terraform plan` fails:

```
Error: Attribute Missing
sub is missing from object
```

It does **not** crash when `nested` is fully specified (e.g.
`nested = { sub = { ref_id = "x" } }`) — only when it is unknown in the plan.

### Notes

- Reproduces only with the **generated CustomType** and when the modified nested
  attribute's **child is itself an object**. A hand-written plain `ObjectType`, or
  a nested attribute with only scalar children, does not crash.
- Related, closed/locked: #767 (PlanModifiers on Custom Type
  NestedAttributeObject/NestedBlockObject) and #754. This still reproduces on
  v1.19.0, and #767 asks that similar findings be filed as a new issue.
